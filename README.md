# ENGEDI SELECT — 상품 소개 사이트

엔게디 의류몰과 별도로 공개하는 생활잡화 편집숍입니다. 이 저장소에는 검토한 공개용 파일만 포함되어 있습니다.

## Render 설정

- 서비스: **Static Site**
- Branch: **main**
- Root Directory: **비워 둡니다.**
- Build Command: **true**
- Publish Directory: **public**
- Auto Deploy: **Off** — 변경 검토 후 수동 배포합니다.
- 환경변수, 데이터베이스, 유료 디스크, AI API 키: 필요하지 않습니다.

별도 서비스 이름 `engedi-select`를 사용하고 기존 `engedi-atelier` 서비스는 변경하지 않습니다. 이름을 사용할 수 없으면 Render에서 다른 고유 이름을 선택합니다. 공개 주소는 실제 서비스 생성 후 확인합니다.

## 제공 범위

상품 검색·분류·상세 정보·관심상품·장바구니를 제공합니다. 관심상품과 장바구니는 현재 브라우저에만 저장되며 기기 간 동기화되지 않습니다.

현재 포함된 8개 상품은 **예시 상품**입니다. 이미지·가격·소재·규격은 시안이고 실제 판매 상품이 아닙니다. 화면에 예시임을 표시하며 실제 문의 접수나 구매가 되지 않습니다. 실제 상품은 권리가 확보된 사진과 확인된 정보로 교체한 뒤 공개하세요.

**온라인 관리자·온라인 문의 접수·결제·주문 확정·배송비 계산·회원가입·AI API는 연결하지 않았습니다.** 정적 사이트는 상품 소개용이며 브라우저에서 비밀번호를 검사하는 관리자를 제공하지 않습니다.

## 상품 수정과 갱신

기존 PC의 엔게디 셀렉트 관리자에서 수정한 뒤 `EXPORT_SELECT.cmd`로 새 공개용 파일을 내보냅니다. 검토된 파일만 이 저장소의 `public/`에 반영하고, 삭제된 상품 사진도 함께 제거하세요. Render에서 **Manual Deploy → Deploy latest commit**을 실행한 뒤 실제 공개 페이지를 확인합니다. PC에서 저장한 내용은 자동으로 인터넷에 반영되지 않습니다.

원본 프로젝트 전체, 관리자 파일, DB, 비밀번호 파일, 개인 문의, 비밀키, `.env`, 비공개 백업을 업로드하지 마세요. 로컬 서버는 관리용으로 유지하고 인터넷에 직접 노출하지 않습니다.

무료 정적 호스팅도 제공자의 사용 한도와 정책을 따릅니다. 새 유료 서비스나 결제 정보를 추가할 필요가 없습니다.
