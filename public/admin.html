FROM STUDIO TO STORE

저장과 공개는 별도입니다.

지금 관리 화면은 이 PC의 상품과 사진을 저장합니다. 인터넷에 공개된 사이트는 공개 파일을 갱신해야 바뀝니다.

01

내용 저장

상품과 메인 화보를 수정하고 저장합니다. 스토어 미리보기에서 확인하세요.

02

공개 파일 준비

이 프로젝트의 공개용 내보내기 도구로 상품과 사진을 묶습니다. 관리자 비밀번호와 고객 문의는 공개 파일에 포함하지 않습니다.

03

공개 사이트 갱신

검토한 공개 파일을 호스팅에 올려 반영합니다. 아직 이 관리자에서 자동 배포는 연결되지 않았습니다.

고객이 보는 기능

상품 소개와 검색, 관심 상품, 문의 접수를 제공합니다. 이 사이트에는 결제와 자동 주문 기능이 없습니다.
